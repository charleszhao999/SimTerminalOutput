SimTerminalOutput - 程序化使用示例

这个页面展示了如何在你的项目中程序化使用 TerminalImageGenerator。

示例 1: 基本使用

// 引入脚本后，创建生成器实例
const generator = new TerminalImageGenerator();

// 生成图片
const text = "$ echo 'Hello World'\\nHello World";
generator.generate(text);

// 下载图片
generator.download('my-terminal.png');

示例 2: 自定义配置

// 自定义宽度、字体大小和内边距
generator.updateConfig({
    width: 600,
    fontSize: 14,
    padding: 15
});

const text = "$ npm test\\nRunning tests...\\n✓ All tests passed!";
generator.generate(text);

示例 3: 中文支持

// 完全支持中文和其他Unicode字符
generator.updateConfig({
    width: 700,
    fontSize: 16,
    padding: 20
});

const text = "$ 运行程序\\n程序启动成功！\\n服务器运行在: http://localhost:3000";
generator.generate(text);

示例 4: 获取图片数据URL

// 生成图片后，可以获取Data URL用于其他用途
const text = "$ git status\\nOn branch main\\nnothing to commit";
generator.generate(text);

// 获取PNG格式的Data URL
const dataURL = generator.toDataURL('image/png', 1.0);
